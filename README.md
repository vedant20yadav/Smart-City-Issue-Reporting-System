# Smart City Issue Reporting System

A Flask-based web application for reporting city issues and managing them through an admin dashboard and analytics page.

## Features
- Report city issues
- Admin dashboard to update or delete issues
- Analytics dashboard with charts
- Bootstrap-based responsive UI

## Tech Stack
- Python Flask
- MySQL
- HTML/CSS/Bootstrap
- Chart.js

## Setup
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Create the MySQL database and table
4. Run the app:
   python app.py

## Database
Configure MySQL credentials in `app.py` or environment variables.
